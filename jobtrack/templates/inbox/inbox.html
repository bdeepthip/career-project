Set up automatic forwarding from Gmail (about 3 minutes)
  1. In Gmail, open Settings → See all settings → Forwarding and POP/IMAP, click Add a forwarding address and paste the address above.
  2. Gmail sends a confirmation code to that address. Refresh this page in a minute: the code appears in your emails below. Enter it in Gmail and click Verify. (Leave forwarding itself set to Disable; the filter in the next step forwards only job emails.)
  3. Go to Filters and Blocked Addresses → Create a new filter. In Has the words, paste:
  4. Click Create filter, tick Forward it to, choose your GAJ address, and click Create filter. You'll still get every email in Gmail as usual.

Outlook: Settings → Mail → Rules → Add new rule → "Forward to" your GAJ address.
